# Buscador de Precios Vigentes de Combustibles en Argentina

## Descripción del proyecto

Aplicación desarrollada en Python para consultar, comparar y analizar precios de combustibles en estaciones de servicio de Argentina.

El sistema permitirá buscar estaciones según una localidad, un tipo de combustible y una fecha de referencia, seleccionando los precios vigentes y ordenando los resultados de menor a mayor precio.

## Objetivo

Facilitar la comparación de precios de combustibles mediante el procesamiento de datos estructurados, aplicando técnicas de lectura, validación, limpieza, transformación y análisis.

## Funcionalidades previstas

- Importar datos desde archivos CSV y JSON.
- Validar los registros y detectar inconsistencias.
- Consultar precios por localidad y combustible.
- Seleccionar el precio vigente a una fecha determinada.
- Ordenar los resultados por precio.
- Calcular estadísticas básicas.
- Exportar resultados a archivos CSV.
